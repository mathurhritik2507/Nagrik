# Nagrik Web 2.1 — Password Recovery, Weekly Crates & Civic AI

## What is included

### Forgot password (web + Android)
- **Login → Forgot password?** opens a password reset form.
- Uses Firebase `sendPasswordResetEmail` and shows generic confirmation without exposing whether an email address is registered.
- Confirm Firebase Authentication Email/Password sign-in is enabled.
- Test reset delivery, password change, expired link behavior, and sign-in using the new password.

### Weekly missions & crates (web beta)
- Ten rotating-capable civic mission templates spanning cleanliness, waste, water, learning, accessibility and community.
- Users submit a photo and explanation. Each unique mission counts once during a Monday–Sunday week **in UTC**.
- Three **different** mission submissions in the current week unlock one **virtual reward crate**.
- Opening the crate grants a deterministic digital badge (e.g., Community Spark). One badge claim per week per account/browser.
- These missions and photos are **not independently verified**; crates are local browser data.
- **No real vouchers, discounts, cash, or prizes are offered.** A future voucher system requires a sponsor or budget, server-side ledger, fraud prevention, terms, and controlled redemption.

### AI Civic Assistant (web)
- Users can ask open-ended civic questions in a conversation; replies are generated by an external AI API.
- Supports general civic learning: sustainability, public infrastructure, community participation, reporting approaches, accessibility, waste and sanitation, etc.
- Verifies the user's Firebase ID token on the server before an AI request, limits inputs to 600 characters and output length, and uses a best-effort per-instance throttle.
- The API key is **server-side only**. Never add it to `firebaseConfig.js`, `package.json`, `.env` committed to Git, or `EXPO_PUBLIC_*`.

## Activate the AI endpoint (required action by project owner)

1. Create an OpenAI API key using your own API account and define strict monthly spending limits.
2. Open the Vercel **Nagrik** project → **Settings → Environment Variables**.
3. Add `OPENAI_API_KEY` as a **secret environment variable** (Production and Preview if you want preview testing).
4. Optional: `OPENAI_MODEL` (default: `gpt-4o-mini`).
5. Optional: `FIREBASE_WEB_API_KEY` (defaults to the project's public Firebase web key already present in the client config).
6. Redeploy from the latest feature-branch commit. A redeploy is necessary after changing variables.
7. Sign in to the preview, open Civic AI from Home, and ask different civic questions.
8. Review Vercel Function logs if you see a configuration or upstream service error.

The API endpoint is `POST /api/civic-assistant` and is protected by a Firebase bearer token. No request from an unauthenticated user should reach the model.

**Production caution:** The built-in throttling is best effort per warm serverless instance and is not a production-grade abuse limit. Before announcing broad public AI availability, enable Vercel WAF rate limiting or a shared rate limiter (such as Redis), set provider spend limits, add abuse monitoring, and consider account-email verification or CAPTCHA during signup.

## Limits and privacy

- Nagrik is not affiliated with municipal government and does not automatically forward grievances to authorities.
- Web activity records, weekly proofs and badges are currently kept in the signed-in user's browser storage, **not** securely verified server-side and **not** synced across devices.
- The external AI provider processes text sent as part of an AI question. Do not include personal identifiers, passwords, precise home addresses, or sensitive third-party data.
- AI may be inaccurate, especially with laws, government offices, local contact details and emergency instructions. Check official sources.
- If you need **real vouchers**, set up sponsor arrangements and a reviewed secure reward backend first.
